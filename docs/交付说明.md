## 演示顺序

1. 打开《岳阳楼记》，切换原文、注释、译文、赏析。
2. 划选“先天下之忧而忧”，查看释义、语法、译文、知识和提问；也可使用段落旁的“研读”。
3. 打开讨论查看知乎检索；外部服务限流时可使用站内搜索入口，或在设置中切换明确标注的演示数据。
4. 保存、编辑与导出笔记。笔记只保存在当前浏览器。
5. 打开阅读设置，测试主题、字号与 AI 配置。

真实 AI 需要有效的服务商密钥和模型 ID。页面配置只保留在当前页面内存，刷新后清除；本次没有真实 AI 密钥，因此未将模型调用质量标记为已验收。

## 运行与构建

使用 Node.js 22.12+，在项目目录执行：

```bash
npm ci
npm run dev
```

生产模式：

```bash
npm run build
npm test
npm run preview
```

访问 http://127.0.0.1:4173。`dist/server/index.js` 为包含静态资源的 Worker；`dist/client` 为前端产物。公开线上版运行 Worker；`backend` 中保留独立 Flask 服务及其依赖说明。
